# Documentation (Docs) Directory

This folder is the central repository for all project documentation.

## Usage
* **API Documentation:** Markdown files detailing API contracts (though FastAPI provides Swagger UI out of the box at `/docs`).
* **Architecture Diagrams:** Mermaid files, PNGs, or PDFs detailing the system architecture.
* **User Manuals:** Guides for operators on how to use the VisionSpec QC dashboard, submit Human-in-the-Loop feedback, and interpret Grad-CAM heatmaps.
* **Meeting Notes:** Sprint planning and task distribution documents for the team.
